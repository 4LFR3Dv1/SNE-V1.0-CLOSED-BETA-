# ⚡ INSTALAÇÃO RÁPIDA DO NODE.JS (Alternativa)

Se a instalação via Homebrew estiver demorando muito, você pode usar o instalador oficial que é mais rápido.

## 🎯 Opção Rápida: Instalador Oficial

### 1. Baixar Node.js

Acesse: **https://nodejs.org/**

Baixe a versão **LTS** (Long Term Support) - v20.x ou v22.x

### 2. Instalar

- Abra o arquivo `.pkg` baixado
- Siga o assistente (Next, Next, Install)
- Aceite os termos
- Aguarde a instalação (~2-3 minutos)

### 3. Verificar

Abra um **NOVO terminal** e execute:

```bash
node --version
npm --version
```

### 4. Instalar dependências do frontend

```bash
cd /Users/renan/Desktop/SNE_BACKUP_CLEAN/frontend
npm install
```

---

## ⏱️ Comparação

| Método | Tempo | Vantagem |
|--------|-------|----------|
| **Homebrew** | 10-30 min | Atualizações fáceis |
| **Instalador Oficial** | 2-3 min | Mais rápido |

---

**Recomendação:** Se estiver com pressa, use o instalador oficial. Se pode esperar, deixe o Homebrew terminar (é melhor para gerenciamento futuro).

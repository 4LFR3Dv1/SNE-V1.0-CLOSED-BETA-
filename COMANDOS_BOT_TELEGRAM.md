# 🤖 COMANDOS DO BOT TELEGRAM - SNE RADAR

## 📋 **COMO USAR**

Agora o sistema `main.py` aceita comandos do Telegram diretamente no terminal!

### **COMANDOS DISPONÍVEIS:**

#### 🔹 **BÁSICOS:**
- `/start` - Iniciar bot e ver boas-vindas
- `/ajuda` - Lista completa de comandos
- `/demo` - Análise demo gratuita (limitada)
- `/planos` - Ver planos premium disponíveis

#### 🔹 **PREMIUM:**
- `/analise` - Análise técnica completa
- `/relatorio` - Relatórios técnicos automáticos
- `/status` - Status da conta do usuário
- `/upgrade` - Upgrade de plano

## 🚀 **EXEMPLOS DE USO:**

```bash
# No terminal do main.py:
Comando >> /start
Comando >> /demo
Comando >> /ajuda
Comando >> /planos
```

## 📊 **FUNCIONALIDADES:**

### **Comando `/start`:**
- Mostra boas-vindas
- Explica funcionalidades do sistema
- Lista comandos básicos

### **Comando `/demo`:**
- Executa análise demo do BTCUSDT
- Mostra preço, tendência, score
- Inclui níveis de suporte/resistência
- **Limitação:** Análise simplificada

### **Comando `/ajuda`:**
- Lista todos os comandos disponíveis
- Mostra exemplos de uso
- Explica funcionalidades por plano

### **Comando `/planos`:**
- Mostra planos FREE, PREMIUM, INSTITUCIONAL
- Lista funcionalidades de cada plano
- Informações de contato para assinatura
